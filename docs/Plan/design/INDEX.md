# 디자인·화면 목록

**원본 미등록 · 빈 양식 · 실제 백업 아님**

온라인 원본과 실제 적용 개정본을 확인한 뒤 해당 내용으로 갱신한다. 원본 등록·조회·백업이 이루어지기 전에는 현재 기획이나 검증 근거로 사용하지 않는다.

Figma 프로젝트 원본·화면설계·SVG·PDF는 아직 없다.
| 화면 ID | 기능 ID·화면 이름 | Figma 프레임 링크 | 설명 원본 | 개정·전달 상태 | 화면설계·SVG·PDF | 누락·시각 확인 |
|---|---|---|---|---|---|---|

[화면 양식](../../templates/SCREEN.md)으로 상태·동작·입력·연결 조건을 설명한다.
화면설계가 Notion에 있으면 해당 페이지도 별도 source_id로 등록한다.
screens/S-xxx.md, svg/S-xxx.svg와 PDF 사본은 실제 원본 전달 뒤 생성한다.
원본 프레임, 화면설계, SVG·PDF의 적용 개정이 맞는지 확인한다.
정적 파일만으로 클릭·오류·로딩·취소 동작이 설명됐다고 보지 않는다.
