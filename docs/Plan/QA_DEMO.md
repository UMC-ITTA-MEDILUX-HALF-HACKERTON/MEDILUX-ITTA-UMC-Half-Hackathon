### 6. 검증 범위와 시연 기준

이번 검증 대상은 확정 정책·상태 전이·계산 예시·문서와 설정·원본과 백업의 일치다. 이번 검증은 문서 저장소를 대상으로 하며 별도 frontend·backend 저장소의 제품 실행은 수행하지 않았다. 카카오지도 로딩·GPS 실기기·웹 푸시·다중 사용자 동작은 실행 검증 대상이 아니었다. 아래는 구현 후 확인할 시연 체크리스트이며 문서 검토 PASS와 구분한다.

- [ ] 서로 다른 기기에서 같은 모임 입장, 최초 약속 좌표·시각·P 공유.
- [ ] 첫 참가자 입장 후 최초 약속 잠금, 후보 필수 입력·수정 권한·득표 잠금 확인.
- [ ] 투표 변경 시 중복 집계 없음, 동률·미응답·0표에서 주최자 확정, 확정 후 잠금.
- [ ] 카카오지도 키·등록 도메인·실제 지도 로딩 및 최초 장소 기준 직선 거리 확인.
- [ ] 100m·50m 경계와 서로 다른 유효 측정 2회, 오래된 좌표·오차 초과·재활성화 금지 확인.
- [ ] GPS 미공유·중단·오래됨·근처 상태 구분, GPS와 도착 상태 독립.
- [ ] 주최자 도착 확인·시각 정정·정시/지각 경계·게임 후 정산값·확인 취소 제한 검증.
- [ ] 30분 전·10분 전·정각, 최초 후보·최종 결정 알림의 대상·중복·지난 알림·모임 종료 처리.
- [ ] 웹 푸시 미허용·미지원에서도 화면 내 안내·투표, 지원 기기에서 앱 밖 알림 실제 수신.
- [ ] 경기 명단·게임·지각 시간·배율 고정, 60초 종료·90초 제출 기한·누락 무효·상대 0명·여러 지각자·두 게임 통산 1회 제한.
- [ ] 0초·1초·10분·20분 직전·정확히20분·20분 초과의 두 배율, 대상 지각자만 핸디캡, 시작 전·후 도착 시각 정정.
- [ ] 다른 게임·경기 점수 혼합 차단, 핸디캡에 따른 점수 보너스 없음, 비교 그룹 기본 배율 유지.
- [ ] 물고기 외형·충돌 영역 동시 확대와 최대 크기의 통과 여유, T-Rex 정수 개수·생성 간격·최대2배·회피 가능성을 실제 구현에서 확인.
- [ ] 승리 0·패배 2P·무승부 P, 정확한 평균·중복 제출·P=0·도착 시각 정정 검증.
- [ ] 게임 미완료와 위치 미공유가 공동 결정 흐름을 막지 않음.
- [ ] 여유 시 채팅: 도착/GPS와 무관한 모임 참가자 전원 송수신, 외부인·다른 모임 접근 거절, 공백·500자 경계·작성자/주최자 배지/시각 확인.
- [ ] 여유 시 채팅: 최근 50개·이전 대화·늦은 입장·새로고침 기록 유지·동시 메시지의 순서·중복 없는 재전송 확인.
- [ ] 여유 시 채팅: 화면 표시 중 5초 조회·전송 직후 갱신·숨김/이탈 중단·새 메시지 버튼과 과거 대화 스크롤 유지.
- [ ] 여유 시 채팅: 실제 종료/약속+24시간 중 빠른 C, 정확히 C에서 전송 차단, D=C+24시간 직전/정각/직후의 조회 제한 확인.
- [ ] 여유 시 채팅: 종료 누락·늦은 종료·재접속·새 메시지가 기한을 연장하지 않고 GPS 당일 종료·모임 상태·투표·게임 처리에 영향 없음.
- [ ] 여유 시 채팅: 만료 즉시 API 조회 차단, 매시간 삭제·서버 재시작 정리·반복 실행, 일반/시스템 채팅만 지우고 다른 모임·결정·투표·도착·게임 원본 보존.
- [ ] 여유 시 채팅: 최종 확정 이벤트와 시스템 안내 중복 방지, 읽기 전용/만료에는 새 시스템 메시지 없음, 별도 앱 밖 푸시 없음.
- [ ] 채팅 미구현·오류에도 공동 결정 시연 가능. 사용자 제공 시 보관·삭제 검증까지 완료했는지 별도 확인.
