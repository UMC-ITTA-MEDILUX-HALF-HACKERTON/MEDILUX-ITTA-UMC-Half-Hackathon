### 5. 일괄 확정 결정과 남은 기술 인계

사용자가 아래 21개 추천안을 전체 승인했다. 추가 확정은 카카오지도 API이며, 후속 요청으로 와이어프레임 제작을 제외했다.

| --- | --- | --- |
| DEC-01 | 후보 등록 | 누구나 장소명＋활동명, 지도 링크 선택. 자동 추천 제외 |
| DEC-02 | 후보 수정·삭제 | 작성자만, 표를 받은 이력과 최종 확정이 없어야 가능 |
| DEC-03 | 투표 방식 | 1인 1표, 확정 전 변경 가능 |
| DEC-04 | 동률·미응답 | 주최자 직접 확정, 동률·미응답·0표 허용 및 상태 표시 |
| DEC-05 | 확정 후 변경 | 후보·투표 잠금. 재투표·다중 안건 제외 |

제품 정책의 선택은 위 기준으로 정리했다. 기술 스택·실명별 담당·서버 권한 검증·API와 DB 계약·지도 키와 도메인·푸시 제공 환경은 개발 담당의 인계·실행 확인 대상이다. 이름·닉네임만으로 주최자 권한을 판정하지 않으며 중복 투표·경기 결과 중복 반영을 막는 참가자 식별이 필요하다. 여기에서 제품 API 구현 완료를 선언하지 않는다.
