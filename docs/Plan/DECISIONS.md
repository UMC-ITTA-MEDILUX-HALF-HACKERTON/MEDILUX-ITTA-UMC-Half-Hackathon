# 결정 기록

**원본 미등록 · 빈 양식 · 실제 백업 아님**

온라인 원본과 실제 적용 개정본을 확인한 뒤 해당 내용으로 갱신한다. 원본 등록·조회·백업이 이루어지기 전에는 현재 기획이나 검증 근거로 사용하지 않는다.

확정된 제품 결정은 아직 없다.
공통 템플릿 준비에 대한 승인은 실제 아이디어·기능·팀 배정의 승인이 아니다.

| 결정 ID | 일시 | 대상 | 결정·이유 | 관련 기능·정책 | 결정 주체 | 적용 개정·상태 |
|---|---|---|---|---|---|---|

상세 항목은 [결정 양식](../templates/DECISION.md)을 사용한다.
대체된 결정은 삭제하지 않고 새 결정과 연결한다.
