# 기획서

**원본 미등록 · 빈 양식 · 실제 백업 아님**

온라인 원본과 실제 적용 개정본을 확인한 뒤 해당 내용으로 갱신한다. 원본 등록·조회·백업이 이루어지기 전에는 현재 기획이나 검증 근거로 사용하지 않는다.

## 문제와 근거

- 대상 사용자·상황: 미정.
- 풀려는 문제: 미정.
- 관찰 사실·출처: 미정.
- 해석·가설·확인 방법: 미정.

## 해결 방식과 MVP

- 제안할 해결 방식: 미정.
- 핵심 사용자 흐름: 미정.
- 필수 기능: 미정.
- 여유가 있을 때 할 기능: 미정.
- 제외 범위: 미정.
- 핵심 가치와 확인할 성공 기준: 미정.

## 행사와 구현 조건

- 실제 제작 시간·필수 제출물·발표 시간: 확인 후 작성.
- 사전 제작·기존 코드·AI 도구 사용 조건: 확인 후 작성.
- 기술·인원·외부 서비스 제약: 미정.
- 확인된 사실과 미확인 조건을 분리한다.

## 연결과 결정

- 담당표·기능 목록·정책·IA·다이어그램·결정 링크: 등록 전.
- 현재 적용 개정본·전달 상태·결정 담당: 미정.
- 남은 질문·범위 변경 영향: 미정.
