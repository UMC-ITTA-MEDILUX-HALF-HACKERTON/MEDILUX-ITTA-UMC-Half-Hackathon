# 의료 근거 목록

**원본 미등록 · 빈 양식 · 실제 백업 아님**

온라인 원본과 실제 적용 개정본을 확인한 뒤 해당 내용으로 갱신한다. 원본 등록·조회·백업이 이루어지기 전에는 현재 기획이나 검증 근거로 사용하지 않는다.

실제 의료 질문·근거·담당 검토는 아직 등록되지 않았다.
의료 역할이 비활성이면 이 자료를 필수 입력으로 요구하지 않는다.
| 근거 ID | 검토 질문 | 관련 기능·화면 | 원본 링크 | 담당 | 검토 상태·범위 | 개정 | 사본 경로 |
|---|---|---|---|---|---|---|---|

[의료 양식](../../templates/MEDICAL.md)으로 근거·적용 조건·한계·표현을 작성한다.
실제 항목이 생기면 M-xxx.md와 원본 링크를 등록한다.
자료 등록과 전문적 판단·서비스 적용 가능 확인을 구분한다.
