# 기능 목록

**원본 미등록 · 빈 양식 · 실제 백업 아님**

온라인 원본과 실제 적용 개정본을 확인한 뒤 해당 내용으로 갱신한다. 원본 등록·조회·백업이 이루어지기 전에는 현재 기획이나 검증 근거로 사용하지 않는다.

실제 기능·우선순위·배정은 미정이다.
| 기능 ID | 이름·목적 | 필수/여유 시/제외 | 담당·검토자 | 의존 기능 | 원본 링크 | 개정·전달 상태 | 사본 경로 |
|---|---|---|---|---|---|---|---|

상세 기능은 [기능 양식](../templates/FEATURE.md)을 기준으로 작성한다.
기능마다 원본 페이지와 백업 경로를 SOURCES.yaml에 추가하고 백업 기록을 연결한다.
정책·화면·API·검증을 기능 ID로 연결한다.
