### 2. MVP 기능

| ID | 기능 | 확정 범위 | 완료 기준 |
| --- | --- | --- | --- |
| F-001 | 모임 생성·링크 참여 | 주최자가 최초 약속 장소·좌표·날짜·시간·기본 지각비 설정. 링크와 닉네임으로 참여 | 동일 모임·참가자·일시 확인. 첫 초대 참가자 입장 후 최초 약속 장소·일시 잠금 |
| F-002 | 당일 위치·장소 기준 거리 | 카카오지도에 공유 위치와 최초 약속 장소까지 직선 거리 표시. 100m 내 유효 측정 2회 연속이면 GPS 갱신·전송 중단 | 개인 마커 숨김·‘장소 근처 · GPS 꺼짐’ 표시. 실제 도착과 구분. 권한 거부·중단·오래된 위치 상태 제공 |
| F-003 | 장소·활동 후보 등록 | 누구나 장소명과 활동명 등록, 지도 링크 선택. 작성자만 수정·삭제 가능하며 표를 받은 후보는 잠금 | 필수 입력 확인. 1표라도 받은 이력 또는 최종 확정 이후 후보 수정·삭제 제한 |
| F-004 | 후보 투표 | 1인 1표, 최종 확정 전까지 변경 가능 | 중복 집계 방지. 투표 수·미응답 수 표시. 확정 후 투표 잠금 |
| F-005 | 최종 결정·공유 | 주최자가 후보 1개 직접 확정. 동률·미응답·0표여도 가능하며 상태 표시 | 전원이 같은 결과 확인. 확정 후 후보·투표 잠금. 재투표·여러 안건 동시 진행 제외 |
| F-006 | 지각비 게임 대결 | 실제 도착 확인 후 주최자가 T-Rex 또는 물고기 점프 중 하나를 선택. 경기의 지각자 1명에게 지각 비례 핸디캡, 나머지 도착자 전원은 기본 조건 | 같은 게임·경기의 도착자 평균과 비교해 0·2P·P. 20분에서 물고기 크기 최대 1.5배·T-Rex 장애물 수 최대 2배. 최대 60초, 두 게임을 통틀어 지각자별 1회 |
| F-007 | 주최자 도착 관리 | 도착 확인 시각 자동 기록, 주최자가 실제 도착 시각 수정. 도착 여부·지각 시간 표시 | 수정값 기준 지각 시간 재계산. GPS 없이도 주최자가 확인 가능. 게임 후 정정에 따른 지각비 반영 |
| F-008 | 남은 시간·참여 안내 | 화면 내 시간 표시·안내 우선 구현, 앱 밖 웹 푸시 후순위 구현 | 30분 전·10분 전·정각 각각 1회. 최초 후보 참여 안내·최종 결정 안내. 미허용·미지원 시 화면 내 안내 유지 |
| F-009 | 모임 단체 채팅 — 여유 시 | 모임별 1개, 참가자 전원 자유 텍스트 대화. 최대 500자, 작성자·시각, 최근 50개와 이전 대화, 실패 재전송, 최종 결정 시스템 안내 | 송수신·기록 조회·중복 없는 재전송. 종료 후 읽기 전용 24시간, 만료 즉시 조회 차단, 시간 단위 삭제·재시작 정리. 미종료 모임은 약속 시각 24시간 후 채팅만 읽기 전용 |

카카오지도는 지도·마커·최초 약속 좌표와 직선 거리 표시를 위한 선택이다. 경로·내비게이션·도착 예상 시간·자동 장소 추천은 제외한다. GPS 권한 없이도 후보·투표에 참여한다. 실제 GPS는 브라우저 위치 API에서 얻고 카카오지도에 표시한다.

기능별 구현 순서는 공동 결정 흐름을 우선 연결한다. F-008 안에서는 화면 내 안내부터 구현하고 웹 푸시는 후순위로 진행한다. F-009 전체도 ‘여유 시’인 MVP 후순위다. 웹 푸시와 채팅 사이의 추가 선후관계는 개인별 개발 인계에서 조율한다. 후순위는 제외를 뜻하지 않으며 미구현 기능은 인계·시연에서 구분한다. 채팅 미구현·오류가 후보·투표·최종 결정 흐름을 막지 않는다.
