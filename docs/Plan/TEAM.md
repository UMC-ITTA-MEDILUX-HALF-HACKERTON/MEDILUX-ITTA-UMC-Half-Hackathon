# 팀과 담당 배정

**원본 미등록 · 빈 양식 · 실제 백업 아님**

온라인 원본과 실제 적용 개정본을 확인한 뒤 해당 내용으로 갱신한다. 원본 등록·조회·백업이 이루어지기 전에는 현재 기획이나 검증 근거로 사용하지 않는다.

실제 참가자와 배정은 미정이다. 역할 명칭만으로 사람이나 권한을 확정하지 않는다.

| 식별명 | 역할·겸임 | 현재 역할 | 기술 영역 | 기능·작업 ID | 편집 범위 | 검토자 | 연결 상대 |
|---|---|---|---|---|---|---|---|

## 공통 책임

- 기획·범위 조정 담당: 미정.
- 디자인 인계 담당: 미정.
- 개발 통합 담당: 미정.
- 공통 API·DB·공유 파일 변경 담당: 미정.
- 발표·시연 담당: 미정.
- 원본·백업 갱신 담당: 자료별 지정 전.

## 배정 변경

| 일시 | 변경 대상 | 이전·새 배정 | 이유 | 인계 내용 | 확인한 사람 | 적용 개정 |
|---|---|---|---|---|---|---|

개인 역할 파일은 이 배정과 구체적인 작업 요청을 참조한다.
미정·충돌은 해당 항목을 확인하며, 역할 파일에만 변경을 남기지 않는다.
