# 정보 구조

**원본 미등록 · 빈 양식 · 실제 백업 아님**

온라인 원본과 실제 적용 개정본을 확인한 뒤 해당 내용으로 갱신한다. 원본 등록·조회·백업이 이루어지기 전에는 현재 기획이나 검증 근거로 사용하지 않는다.

- 대상 사용자·권한: 미정.
- 적용 기능·개정: 미정.
- 작성·검토 담당: 미정.

## 화면·메뉴 구조

|---|---|---|---|---|---|---|

## 핵심 사용자 흐름

- 시작 → 주요 행동 → 결과: 미정.
- 뒤로 가기·취소·실패 후 이동: 미정.
- 관련 다이어그램 ID·원본 링크: 미정.

## 확인

- 기능에 연결되지 않은 화면·빠진 진입점: 미확인.
- 개발·디자인과 확인한 내용: 미확인.
- 남은 질문: 미정.
