# 참여와 협업 안내

너빼고다옴의 확정 정책 PM-MVP-v2.0이 팀 Notion에 등록되어 있다. 모바일 우선 웹앱·카카오지도 API를 적용하며 Medical은 비활성이다. 개인별 기능 담당과 나머지 기술 스택은 미정이다.
[프로젝트 설정](PROJECT_CONFIG.yaml)에서 행사와 활성 역할을 확인한다.
[최초 질문](ONBOARDING.md) 후 각자 개인 설정을 만든다.

## 문서의 역할

- 루트 AGENTS.md: AI의 공통 시작·수행 규칙.
- 역할별 README: 해당 역할의 수행·검증·소통·인계.
- Plan: 원본을 찾는 입구와 온라인 원본의 백업.
- Coding 계약·통합·인계: 코드와 함께 관리하는 기술 기준.
- templates: 작성용 빈 양식. 실제 요구사항이나 확정 결정이 아니다.
- .local: 개인 역할·접근 결과·캐시. 다른 사람에게 배포하지 않는다.

## 소통

짧은 전달에는 다음 네 항목을 사용한다.
- 현재 작업: 작업 ID·기능 ID와 지금 하는 일.
- 완료: 실제 결과와 확인한 것.
- 막힘: 원인·영향 기능·기다리는 대상.
- 필요한 결정: 선택지와 결정이 필요한 시점.
담당 변경은 공통 담당표와 개인 설정에 함께 반영한다.
대화에서 결정된 제품 조건은 담당자가 원본 결정 기록·관련 기능에 반영한 뒤 개정본을 알린다.
공유 파일은 한 명의 변경 담당을 지정하거나 겹치는 편집을 순차로 수행한다.

## 상태를 섞지 않기

- 역할: 미정 / 역할 확인·업무 미정 / 담당 확정.
- 자료: 빈 양식 / 작업 중 / 개발 전달 완료 / 대체됨.
- 검토: 미검토 / 검토 중 / 반영 가능 / 추가 확인 필요.
- 검증: PASS / FAIL / N-A. 실행하지 못한 항목은 미검증 사유를 별도로 기록한다.
문서 작성, 검토, 제품 결정, 코드 검증, 실제 시연은 서로 다른 상태다.

## 우선순위

기능 우선순위는 필수 / 여유 시 / 제외로 쓴다.
'필수'는 핵심 데모를 성립시키는 기능이다. 다른 도구의 P0·P1 등과 자동 치환하지 않는다.
모든 문서를 완성한 뒤 구현을 시작할 필요는 없다.
기능의 목적·정책·입출력·담당·완료 기준을 맞춘 뒤 각 파트가 세부 내용을 보완한다.

## 원본 등록과 최초 접근 시험

1. 자료 담당이 SOURCES.yaml에 실제 페이지·프레임 URL과 백업 위치를 등록한다.
2. 각 참가자의 환경에서 필요한 본문·하위 자료·화면·설명을 읽는다.
3. 로그인 화면·빈 화면·미리보기 제목만 보이면 본문 읽기 성공으로 처리하지 않는다.
4. 허용된 실제 변경 후 다시 읽어 수정 반영을 확인한다. 읽기 시험을 위해 원본을 임의 수정하지 않는다.
5. 개인 설정의 source_access에 자료 ID·접근 방법·확인 시각·상태·미확인 범위를 기록한다.
공개 링크의 성공이 연결 도구의 접근 권한을 증명하지는 않는다.
계정·플랜·도구별 조회 한도는 실제 환경에서 확인하고 공유 자격 증명을 만들지 않는다.

## 개인 캐시

실제 읽기가 시작된 뒤에만 .local/cache/INDEX.yaml과 필요한 파일을 만든다.
항목에는 source_id, 읽은 범위, 원본 개정 번호, 확인 가능한 수정 시각,
실제 조회 시각, 저장 경로, 완전성·누락, 마지막 접근 결과를 기록한다.
목록이 남아 있어도 본문·이미지가 없으면 해당 내용을 보유한다고 판단하지 않는다.
캐시는 개인 재사용용이며 공통 백업의 최신성을 대신 증명하지 않는다.

## 생성·권한 상태

원격 저장소 연결 상태는 PROJECT_CONFIG.yaml의 repository 항목과 실제 Git에서 확인한다.
팀 Notion 작업 공간은 [원본 목록](SOURCES.yaml)의 team_workspace에 등록했다.
[PM의 MVP 묶음](https://app.notion.com/p/418c0efa070a80c29109cd7db7143067)은 plan.mvp에 연결했다. 기획·기능·정책·IA·결정·담당·QA는 같은 Notion 페이지에서 범위별로 보관한 사본이다. 와이어프레임은 사용자 요청으로 제외했으며 개발 환경은 후속 구성 사항이다.
읽기·검토를 요청받았다는 이유로 링크 공개 범위나 계정 권한을 변경하지 않는다.
제작 문서는 특정 AI 도구의 자동 로딩이나 접근 제한을 보증하지 않는다.
