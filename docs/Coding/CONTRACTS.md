# 기술 연결 계약

기술 스택·API·데이터 구조는 미정이다. 아래는 빈 등록 양식이다.
실제 정의가 코드나 스키마에 있으면 정확한 위치를 연결하고 이 문서에 전부 복제하지 않는다.

## 계약 목록

| 계약 ID | 기능 ID | 목적 | 정의 위치 | 담당 | 연결 상대 | 상태·버전 |
|---|---|---|---|---|---|---|

## 계약별 필수 확인

- 입력·출력·필수 여부·자료형·허용 범위.
- 인증·권한·상태 전이·오류·재시도·중복 요청 처리 중 해당하는 항목.
- 필드의 의미와 DB 관계·제약.
- mock 여부와 실제 연결 확인 상태.
- 변경 담당·검토자·영향 파트·적용 버전.

## 미결정 사항
