## 검토 중 명확하게 한 연결 조건

- 기존 ‘동일 난이도·장애물’ 조건을 같은 게임·기본 환경＋선택 지각자만 핸디캡으로 개정했다. F-006·S-003/004·POL-GAME-001/003/004·DEC-17/18/22/23·QA를 함께 갱신했다.
- L은 실제 지각 초, r=min(L/1200,1), 물고기 1+0.5r, T-Rex 1+r이다. 0초·1초·10분·20분 직전·정확히20분·직후·초과와 0~3600초 구간의 단조 증가·상한을 검증했다.
- 20분은 배율 상한이며 실제 지각 시간을 잘라내지 않는다. 화면 표시용 분 단위 반올림을 계산에 쓰지 않는다.
- 경기 시작 전 시각 정정은 새 배율에 반영하고 시작 후에는 게임·L·배율·명단·점수를 유지한다. 지각비 정정 규칙은 유지한다.
- 비교 그룹의 다른 지각자는 기본 조건이다. 주최자 게임 선택·같은 게임/경기 점수만 비교·게임 변경 재도전 금지·핸디캡 점수 보너스 없음도 검토했다.
- 두 게임의 정수 장애물 생성·충돌 영역·최대 크기 통과 여유·실제 재미와 난이도는 실행 가능한 게임에서 추가 검증해야 한다.

- 모임 개설의 기능 연결용 화면 목록에 최초 장소 좌표와 기본 지각비 입력을 보완했다. 와이어프레임 생성은 포함하지 않는다.
- 후보는 현재 표 수가 0이어도 표를 받은 이력이 있으면 수정·삭제 잠금을 유지한다.
- 최초 약속 잠금은 첫 초대 참가자 입장 시점이며 다음 장소 확정으로 GPS 기준을 바꾸지 않는다.
- 같은 좌표 측정을 반복 이용해 GPS 유효 측정 2회로 세지 않는다. 오차 초과·오래된 측정·범위 밖·실패는 연속 횟수를 초기화한다.
- 페이지가 닫혔다는 사실을 원격에서 즉시 알 수 있다고 가정하지 않는다. 미갱신 시간으로 오래된 위치를 구분한다.
- GPS 미공유 참가자도 주최자가 실제 도착을 확인할 수 있다. GPS 상태와 도착 상태는 독립이다.
- 게임 후 실제 도착 정정은 적용 지각비를 재계산하지만 원래 점수·참가 명단을 소급 변경하지 않는다.
- 비교 상대가 0명이면 경기 시작을 막고 기본 지각비 유지 상태를 표시한다. 게임을 시작하지 않았으므로 1회 제한을 소모하지 않는다.
- 중단 또는 모임 종료로 미완료된 경기는 무효이며 점수 누락자를 빼고 평균을 만들지 않는다.
- 시간 안내·GPS 갱신·게임 제한 시간은 별개의 시계이며 약속 시각이 투표 자동 종료 시각을 뜻하지 않는다.

## 저장소 반영

커밋 ID를 이 파일 안에 자기 참조로 고정하지 않는다. Git 이력과 원격 main을 조회해 확인한다.
